#+TITLE: Plan — Phase 2 (Testing & Fake Provider)
#+AUTHOR: Benedict maintainers
#+LANGUAGE: en

* Objective
Introduce a deterministic fake provider so we can write automated ERT/Buttercup tests and run manual dry-runs without hitting OpenRouter. The fake backend should emulate the provider interface (async callbacks, message metadata, retry/error surfaces) to unblock iteration on chat UX and context features.

* Scope
- Provider implementation (`benedict-provider-fake.el`) that optionally scripts responses/errors, defaults to echoing the last user message, and fires callbacks via `run-at-time` to mimic async HTTP.
- Helper API for tests: enqueue scripted replies, clear/reset state, and macros for running blocks with custom scripts/latency.
- docs/devlogs updates explaining when to use the fake provider (unit tests, offline demos) and how to switch `benedict-provider` to `'fake`.
- Initial ERT coverage validating default echo behavior and scripted success/error flows.

* Work Breakdown
1. **Provider scaffolding**: defgroup/defcustom for latency/model; register `'fake` provider alongside OpenRouter.
2. **Script queue helpers**: `benedict-provider-fake-enqueue-response`, `...-enqueue-error`, `...-with-script` macro (or fixture) for deterministic tests.
3. **Async dispatcher**: `run-at-time`-backed response handler that builds metadata (:provider, :model, usage, latency) and error plists mirroring OpenRouter outputs.
4. **Docs/logging**: README “Fake provider” section + devlog note describing how to run tests/manual dry-runs; mention in Phase 2 testing plan checklist.
5. **ERT smoke tests**: add `test/benedict-provider-fake-test.el` verifying echo + scripted error; run via `emacs --batch` when feasible.

* Success Criteria
- Setting `(setq benedict-provider 'fake)` followed by `M-x benedict-chat` produces echo responses without network.
- Tests can enqueue deterministic responses/errors and assert on metadata without waiting on network.
- README/devlogs describe the workflow so contributors know how to use the fake provider for manual/automated validation.
