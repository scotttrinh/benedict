* Summary (2025-11-16)
- Resolved key binding convention warning: "This key sequence is reserved"

* What Changed
- Default prefix changed from C-c b (reserved) to C-c C-b (allowed for packages)
- Introduced a dedicated prefix map and attached it under the customizable prefix
- Updated README example init to use (kbd "C-c C-b")

* Details
- In benedict.el:
  - defcustom benedict-keymap-prefix now defaults to (kbd "C-c C-b")
  - Added benedict-prefix-map and bound it under benedict-keymap-prefix in benedict-mode-map
  - Command mapping now lives under that prefix (e.g., C-c C-b c → benedict-chat)
- In README.org: corrected example to avoid reserved C-c letter binding

* Rationale & Reference
- Emacs key conventions reserve C-c <letter> for users; packages should use C-c followed by a non-letter (e.g., C-c C-b) for their prefixes.

* How To Customize
- Users can pick a different, non-reserved prefix in init:
  (setq benedict-keymap-prefix (kbd "C-c C-b"))
