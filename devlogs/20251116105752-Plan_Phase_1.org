* Objective
Ship a minimal, installable package that opens a chat buffer and performs local echo responses, with a tool registry skeleton and placeholder approvals. No network required.

* Scope (from ROADMAP)
- Create benedict.el with autoloads, defgroup, faces, keymaps, error types
- benedict-chat-mode: buffer creation, message rendering (simple), send command
- benedict-mode minor mode: ask region/defun; echo transform locally
- Tool registry (skeleton): register, list; call with plist args; approval stubs
- Persistence stub: in-memory store; lay down SQLite schema (sqlite.el), migrations scaffold

* File Layout (initial)
- benedict.el                ; package header, core defs, defgroup, errors
- benedict-chat.el           ; chat buffer, major mode, rendering, commands
- benedict-provider-echo.el  ; echo provider implementing Phase 1 :send
- benedict-tools.el          ; registry, approval placeholders
- benedict-persist.el        ; in-memory stub + schema outline
- test/ (ERT)                ; basic tests for buffer/actions/registry

* Implementation Plan
** Package Skeleton
- Header in benedict.el:
  #+begin_src elisp
  ;; benedict.el --- Emacs-first AI assistant  -*- lexical-binding: t; -*-
  ;; Author: Benedict maintainers
  ;; Version: 0.1.0-pre
  ;; Package-Requires: ((emacs "27.1"))
  ;; Keywords: tools, convenience, ai
  ;; URL: https://example.local/benedict
  (provide 'benedict)
  #+end_src
- Defgroup and key prefix variable:
  - (defgroup benedict nil ...) ; top-level
  - (defcustom benedict-keymap-prefix (kbd "C-c b") ...)
  - (defvar benedict-mode-map (let ((m (make-sparse-keymap))) ...))
- Faces: define user/assistant/system/timestamp faces with sane defaults
- Error types: define conditions via define-error (e.g., 'benedict-error)

** Chat Buffer & Mode (=benedict-chat-mode=)
- Commands:
  - (defun benedict-chat () ...) ; opens/creates a chat buffer, switches to benedict-chat-mode
  - (defun benedict-chat-send () ...) ; grabs current input, appends to message log, calls provider
- Rendering:
  - Simple text rendering first (user/assistant with faces); timestamps optional
  - Maintain buffer-local message list (alist or vector)
- Keymap (benedict-chat-mode-map):
  - RET to send; C-c C-k to clear input; q to bury buffer

** Minor Mode (=benedict-mode=)
- Enable in prog/text modes; binds prefix map under benedict-keymap-prefix
- Commands:
  - (defun benedict-ask-region (beg end)) ; send region text
  - (defun benedict-ask-defun ())        ; send defun via beginning-of-defun helpers
  - Both route to chat buffer and insert echo response

** Echo Provider
- (cl-defstruct benedict-provider ...) as per Phase 0 sketch
- Echo implementation of :send that creates a trivial response:
  - Transforms input: e.g., (concat "Echo: " (truncate-string-to-width ...))
  - Returns immediately via on-success callback
  - No network, no keys

** Tool Registry Skeleton
- Implement benedict-tools-register/list/call from Phase 0 stubs
- Seed with a demo tool (e.g., :id 'uppercase) used by echo provider optionally
- Approval UI placeholder:
  - (defun benedict-approval-confirm (spec args) ...) shows a simple buffer with Yes/No using read-char-choice; always returns t for now with a message

** Persistence Stub
- In-memory store:
  - (defvar benedict--threads (make-hash-table :test 'equal)) storing message vectors by thread id (buffer name)
  - Save/load no-ops initially; hooks exist for Phase 7
- SQLite schema outline string and migration scaffold functions guarded by (featurep 'sqlite)

** Autoloads & Discoverability
- Mark interactive entry points with ;;;###autoload (benedict-chat, benedict-mode)
- Provide (transient) key hint later; for now add which-key descriptions if available

** Tests (ERT)
- test/benedict-chat-test.el:
  - opens chat buffer and asserts major-mode is benedict-chat-mode
  - sending a simple message produces an echo line with assistant face property
- test/benedict-tools-test.el:
  - registry add/list/call roundtrip
- test/benedict-mode-test.el:
  - benedict-ask-region uses region text and inserts echo response

* Acceptance Mapping
- M-x benedict-chat opens a buffer; typing and sending creates an echo response
- benedict-ask-region sends region and shows response; no network required
- Tools can be listed and invoked; approval UI shows a placeholder dialog
