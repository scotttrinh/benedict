* Summary (2025-11-16)
- Fixed autoload failure: "Autoloading file benedict.el failed to define function benedict-chat"

* Root Cause
- Doom’s `(use-package! benedict :commands (benedict-chat ...))` autoloaded the main library `benedict.el` when `benedict-chat` was invoked.
- `benedict.el` did not define `benedict-chat` nor provide an autoload for it; the function lives in `benedict-chat.el`.

* Fix
- In `benedict.el`, replaced the forward declaration with an explicit autoload:
  (autoload 'benedict-chat "benedict-chat" "Open Benedict chat buffer." t)
- This ensures calling `benedict-chat` loads `benedict-chat.el` on demand.

* Verification
- M-x doom/reload or eval-buffer `benedict.el`
- Press C-c C-b c → chat buffer opens; C-c C-s prompts and echoes response

* Notes
- We kept `(require 'benedict)` in `benedict-chat.el`; it is safe because `benedict.el` is already loaded when the autoload runs.
