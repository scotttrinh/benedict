* Notes: Phase 6.1 - Layered Autonomy Profiles

** Date
2025-11-20

** Summary
Implemented profile-specific autonomy limits that layer on top of global safeguards. This allows creating specialized profiles (like "Planner") with stricter constraints than the global defaults.

** Changes
1.  **benedict-chat.el**:
    *   Added `benedict-chat--effective-limit` helper to resolve the stricter of global vs. profile limits.
    *   Updated `benedict-chat--check-loop-constraints` to use effective limits.
    *   Updated `benedict-chat-profiles` docstring to document the new `:autonomy` key.
2.  **benedict-agent-loop-test.el**:
    *   Added tests for layered autonomy (profile wins, global wins, fallback).
3.  **README.org**:
    *   Added documentation for "Layered Autonomy Profiles" with an example.

** Key Decisions
*   **Stricter Wins**: Effective limit is `min(global, profile)`. Nil counts as infinity.
*   **Profile Key**: Used `:autonomy` plist with keys `:max-turns`, `:max-time`, `:max-tokens`.

** Verification
*   Ran `nix run .#test` and verified all 46 tests passed, including new safeguard tests.
