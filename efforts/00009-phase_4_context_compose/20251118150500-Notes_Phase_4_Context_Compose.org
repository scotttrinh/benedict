* Summary
- Implemented the Phase 4 skeleton: context slices, compose buffer, minimal profiles, and context-aware “ask” commands.
- Added tests for context formatting and the compose → send path using the fake provider.
- Fixed a compose bug where sending closed both compose and chat buffers without recording the user message.

* What landed
- New =benedict-context.el=:
  - Slice constructor with truncation/size metadata, formatting for compose/send, and summary helpers.
- Chat/compose flow in =benedict-chat.el=:
  - Compose buffer per chat (=*Benedict Compose: <chat>*=) with header (profile/project/context summary), body separator, and commands:
    - =C-c C-c= send (closes compose, returns to chat, inserts user msg, dispatches).
    - =C-c C-k= cancel (clears pending context, returns to chat).
  - Minimal profiles (planning/coding/writing/review) with project-root defaults; preamble folds into outgoing user text.
  - Context capture commands:
    - =benedict-chat-ask-region/defun/buffer/project/git-context= gather slices and insert into compose.
  - Message assembly combines preamble + “Context:” section + user prompt; slices cleared after send by default.
- Tests:
  - =benedict-context-test.el=: truncation + “Context:” formatting.
  - =benedict-chat-test.el=: compose flow sends context/prompt; existing suites unchanged.

* Bug fixed
- Sending from the compose buffer killed both compose and chat, leaving chat empty. Root cause: compose send killed the current buffer (compose) and chat was closed by a buffer-local cleanup path before rendering. Fix: after send/cancel, pop back to the chat buffer, record the user message, then kill compose only.
