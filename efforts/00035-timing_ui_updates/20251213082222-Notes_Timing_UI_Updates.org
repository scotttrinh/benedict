* Notes: Timing + Cost UI (Message Items + Session Time)

** Summary
- Implemented marker-backed assistant message items with refreshable headers.
- Streaming deltas now insert into the message body region (not via point-max hacks).
- Added session total time accumulation (seconds) to chat header-line telemetry.

** Root Cause / Motivation
- Assistant messages were rendered as plain text with no stable markers, so we could not refresh per-message UI (headers) during streaming.

** Key Changes
- Added message item rendering + header rewrite helpers in `benedict-chat-render.el`.
- Updated chat rendering so assistant messages render as items and carry an attached `:item` on the message plist.
- Updated streaming initialization to reuse message item body markers.
- Extended status timer tick to refresh the in-flight message header (elapsed).
- Added telemetry field `:session-seconds` and accumulate it on successful requests.
- Fixed `Eask` to declare the minimum Emacs version as a string so the Nix/Eask runner works.

** Bugfixes + Integration Tests (Streaming / Header Refresh / UX)
- Fixed a streaming clobber issue where header refresh could overwrite streamed assistant body text.
  - Root cause: header rewrite deleted the header sentinel newline, allowing body markers to collapse onto the header start during deletion/reinsert.
  - Fix: rewrite helpers delete only the header text while keeping the existing sentinel newline stable (`benedict-chat-render.el`).
- Stabilized point during periodic header refresh:
  - Header rewrite runs under `save-excursion`, then point is moved to the end of the in-flight message body (`:content-end`) (`benedict-chat.el`).
- Added “integration-style” tests that simulate a simple user → assistant streaming flow without real timers:
  - Asserts streamed body content survives header refresh ticks.
  - Asserts point ends at `:content-end` after header refresh ticks.
  - File: `test/benedict-chat-integration-test.el`.
- Added a blank line between rendered item blocks (messages/tool blocks) to improve readability:
  - Implemented `benedict-chat--maybe-insert-item-gap` and test coverage for the `"\n\n"` boundary between adjacent blocks.
