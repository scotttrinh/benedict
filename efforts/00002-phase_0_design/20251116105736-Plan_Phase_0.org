* Design Decisions (Draft)
** Package Namespace & Conventions
- Library root: =benedict.el=
- Feature provide: =(provide 'benedict)=; public APIs prefixed =benedict-…=
- Internal helpers prefixed =benedict--…=
- Customization group: =(defgroup benedict nil "Benedict AI assistant." :group 'applications)=
- Faces: =benedict-chat-user=, =benedict-chat-assistant=, =benedict-chat-system=, =benedict-chat-timestamp=
- Keymaps: =benedict-chat-mode-map= (buffer UI); =benedict-mode-map= (minor mode, prefix C-c b)

** Provider Interface Sketch (docs + stubs only)
- Protocol (function table or plist):
  - :id (symbol), :name (string), :send (fn plist → callback), :capabilities (plist), :cancel (fn token)
- Minimal send signature (non-streaming for now):
  #+begin_src elisp
  (cl-defstruct benedict-provider id name send capabilities cancel)

  (defun benedict-provider-send (provider request &key on-success on-error)
    "REQUEST is a plist like (:messages [...] :tools [...] :options ...)."
    (funcall (benedict-provider-send provider) request
             :on-success on-success :on-error on-error))
  #+end_src
- Echo provider (Phase 1) will implement =:send= locally (no network)

** Tool Registry Schema (docs + stubs only)
- Entry plist: =(:id SYMBOL :fn FUNCTION :schema PLIST :approval POLICY)=
- =:schema= summarized for args; POLICY one of =auto=, =confirm=, =always=
- Stubs:
  #+begin_src elisp
  (defvar benedict--tools (make-hash-table :test 'eq))

  (defun benedict-tools-register (spec)
    (puthash (plist-get spec :id) spec benedict--tools))

  (defun benedict-tools-list ()
    (let (acc) (maphash (lambda (k v) (push v acc)) benedict--tools) (nreverse acc)))

  (defun benedict-tool-call (id &rest args)
    (let* ((spec (gethash id benedict--tools))
           (fn   (plist-get spec :fn)))
      (apply fn args)))
  #+end_src

** Streaming Plan
- Start non-streaming; design for upgrade. Target SSE via make-process + curl -N to keep UI responsive and parsing simple; fall back to url-retrieve when provider lacks SSE
- Throttled incremental rendering; cancellation via =process-send-signal=

** Security Posture
- Keys: =auth-source= lookup by host; env var fallback (e.g., =OPENAI_API_KEY=)
- Redaction helper for logs: =benedict--redact= masks secrets/paths
- Provenance log fields: timestamp, tool, args (redacted), outcome
